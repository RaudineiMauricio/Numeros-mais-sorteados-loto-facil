# Números Mais Sorteados - Lotofácil

Este projeto tem como objetivo analisar os números mais sorteados na Lotofácil, fornecendo estatísticas baseadas em sorteios anteriores.

##  Funcionalidades
- Coleta de dados de sorteios anteriores da Lotofácil.
- Análise estatística dos números mais frequentes.
- Geração de relatórios e visualizações para melhor interpretação dos dados.

##  Estrutura do Projeto
- `dados/` → Contém os arquivos com os resultados dos sorteios.
- `src/` → Contém os scripts em Python para análise dos números sorteados.
- `README.md` → Documento explicativo sobre o projeto.

##  Como Utilizar
1. Clone este repositório:
   ```bash
   git clone https://github.com/RaudineiMauricio/Numeros-mais-sorteados-loto-facil.git
   ```
2. Acesse o diretório do projeto:
   ```bash
   cd Numeros-mais-sorteados-loto-facil
   ```
3. Instale as dependências necessárias (caso existam):
   ```bash
   pip install -r requirements.txt
   ```
4. Execute o script de análise:
   ```bash
   python src/analisar_numeros.py
   ```

## 🛠 Tecnologias Utilizadas
- Python
- Pandas
- Matplotlib (caso haja visualização gráfica)
